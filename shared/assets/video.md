# OWLCMS Video

Note: This is an optional module.

#####

This module installs the **OWLCMS Video** application for camera capture and jury replay review. It allows

- **Configuration** discovers cameras and enables/disables them.
- **Monitoring** shows each detected camera and controls starting, stopping, previewing, and recording.
- **Replays** selects the cameras and their replay order, records the selected streams

The **Replays** feature uses OWLCMS clock and decision information to create trimmed jury replay videos.

#####

You can optionally run the Camera features on one laptop and the Replays on another; check the Replays menu if you need this.
